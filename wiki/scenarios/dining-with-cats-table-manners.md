# ☕ 貓咖餐飲防護與桌面防貓禮節

> [!CAUTION] 人貓共餐高危禁區：防偷吃、防燙傷、防餐具挑逗！
> 知名藝廊貓咖（如紅玥緬因貓）多採榻榻米席地而坐與低矮桌几設計。貓咪可在桌邊甚至跳上桌面自由穿梭。
> 顧客若疏於看顧餐點，不僅容易發生**貓咪偷吃人類甜點造成急性中毒**，更常因貓咪尾巴掃落**滾燙咖啡引發人貓燙傷**事故！

---

## 📌 重點摘要 (Key Takeaways)
1. **嚴禁用餐具逗弄貓咪**：店規嚴禁使用吸管、叉子、餐匙甚至筷子逗弄貓咪，避免貓咪誤咬受傷或污染餐具。
2. **熱飲加蓋與杯身居中**：熱咖啡、熱茶送上桌時，**務必放置在桌面最中心內側**，切勿放在桌緣以防被貓尾巴或肉墊打翻。
3. **離座「杯蓋與餐罩防護」**：去洗手間或起身逗貓時，必須將飲料蓋蓋好、餐點用罩子或紙巾覆蓋，並請同行親友代為看管。
4. **人類食物全面防守**：人類甜點含大量糖分、乳酪、巧克力、油脂甚至木糖醇；千層麵等鹹食常含洋蔥、青蔥調味，**對貓均具劇毒性**。
5. **落毛免責與個人防護**：貓咖空氣與桌面難免有飄毛，若有打翻或毛髮飄落需自行負責；嚴重貓毛過敏者入店前請備妥抗組織胺藥物。

## 🍽️ 桌面攻防四大守則

```text
守則 1：熱飲置中不靠邊 ──> 守則 2：餐具絕不當玩具 ──> 守則 3：離座必加杯盤蓋 ──> 守則 4：偷吃立即平移推擋
```

| 桌面突發狀況 | ❌ 錯誤應對方式 (危險) | ✅ 正確安全應變 (SOP) |
| :--- | :--- | :--- |
| **貓咪跳上桌子嗅聞蛋糕** | 覺得好可愛，拿叉子沾一點鮮奶油餵貓 | 用手掌做成擋板輕輕阻隔在貓鼻與蛋糕之間，將蛋糕往後移 |
| **貓咪想喝水杯裡的冰水** | 任由貓咪將嘴巴伸進杯子裡喝水 | 蓋上杯蓋，或將水杯移開；若要給水請告知店員提供專用貓水盆 |
| **吸管引起貓咪好奇伸手撥弄** | 拿著吸管像逗貓棒一樣上下晃動逗貓 | **立即拔出吸管放進嘴裡或收好**；吸管被咬裂吞下會形成腸胃穿孔異物 |
| **熱飲不慎被貓咪打翻** | 尖叫並慌亂抽衛生紙擦桌子 | **第一時間先護住貓咪與自己的皮膚**避免熱水燙傷，隨後舉手請店員前來清理 |
