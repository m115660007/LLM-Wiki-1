# 🛑 貓咪警戒與緊迫訊號解讀

> [!WARNING] 緊迫防線：請勿忽視微小警訊！
> 貓咪很少無預警直接攻擊。在發動抓咬之前，牠們一定會透過身體各部位釋放大量「抗議與緊迫訊號」。學會辨識這些訊號，是每位貓咖訪客保護自己與尊重貓咪的必修課。

---

## 📌 重點摘要 (Key Takeaways)
1. **尾巴甩動是焦躁，非開心**：狗搖尾巴代表興奮，但貓咪**尾巴快速甩動、抽動或用力拍打地面**代表內心煩躁不安、隨時可能翻臉。
2. **耳朵警報（飛機耳）**：雙耳向兩側壓平（飛機耳）或向後貼平，代表恐懼、憤怒或自我防禦準備。
3. **瞳孔擴大與凝視**：在光線明亮處瞳孔突然放大成圓形，且身體肌肉緊繃，代表高度緊張或進入戒備攻擊狀態。
4. **聲響示警（哈氣、低吼）**：哈氣 (Hissing) 是明確的「退後！別惹我」防衛性通告，請立即停止所有動作並後退。
5. **慢性壓力行為**：反覆踱步、過度理毛、長期待在暗處不出來，均為環境壓力超載的表徵。

## 📊 警戒程度三級量表 (Stress Escalation Scale)

```text
[輕度煩躁/請停手]                 [中度防禦/停止靠近]              [高度攻擊/立即撤退]
微幅甩尾 / 耳朵向兩側微傾      飛機耳 / 尾巴用力拍地 / 瞳孔放大   哈氣 / 低吼 / 炸毛拱背 / 出爪哈氣
```

| 身體部位 | 警戒/緊迫狀態特徵 | 背後情緒解讀 | 訪客應變動作 |
| :--- | :--- | :--- | :--- |
| **尾巴** | 尾尖急促抽動、整條尾巴大幅度左右甩動、猛抽地面 | 「我已經煩躁了，快停手！」 | **立即停止撫摸**，將手輕緩收回 |
| **耳朵** | 耳朵平貼向兩側（飛機耳）、向後下壓 | 害怕、感到威脅或防衛警戒 | 保持距離，勿繼續前傾身體 |
| **眼睛** | 瞳孔極度放大成黑圓、死盯著特定目標不眨眼 | 緊張、應激、恐懼激動 | 避免直視，移開視線並緩慢眨眼 |
| **背部/毛髮** | 拱起脊椎骨、全身毛髮直立（炸毛）、尾巴變粗 | 企圖擴大體型嚇阻威脅 | 不要圍觀，騰出寬敞通道讓貓離開 |
| **聲音** | 發出嘶嘶聲（哈氣）、低沈喉音（低吼） | 「最後通牒：再過來我就攻擊」 | 絕對不可強行靠近，安靜後退 |

## 🚫 新手最常犯的致命誤區

### 誤區一：「牠在搖尾巴，好開心喔！」
* **真相**：貓咪只有在「緩慢柔和、垂直立起、尾尖微彎成問號」時才代表友好；**急躁拍動地面絕對是焦慮不耐煩**。若此時繼續硬摸，下一秒通常就是出爪攻擊。

### 誤區二：「牠發出呼嚕聲，一定是超享受？」
* **真相**：呼嚕聲並不百分之百等於開心！請詳見 `[[wiki/body-language/purring-dual-meaning|呼嚕聲的雙重含意]]`。當貓咪極度緊張、疼痛或受傷時，也會藉由呼嚕震動進行自我安撫。
